# Bortle estimate grid — build notes

`src/data/bortleGrid.js` is generated by `make_grid.py`. It is a downsampled
version of the World Atlas of Artificial Night Sky Brightness, used to show
an *estimated* Bortle class for arbitrary searched locations. Known ratings
(Medford's inferred 8, dark-sky sites' published values) always take
precedence; the grid only fills gaps.

## Source data

- Falchi et al. 2016, "The new world atlas of artificial night sky
  brightness", Science Advances 2:e1600377
  - Dataset: https://doi.org/10.5880/GFZ.1.4.2016.001 (GFZ Data Services)
  - Paper: https://dx.doi.org/10.1126/sciadv.1600377
- License: **CC BY-NC 4.0** (non-commercial). The 2016 README in the download
  prohibited redistribution, but it defers policy changes to the data access
  webpage, which moved the license to CC BY-NC 4.0 in November 2019.
  Stargazer is a free non-commercial app; if it ever becomes commercial, this
  dataset must be replaced or re-licensed.
- File: `World_Atlas_2015.tif` (~3 GB, 30 arcsec, float32) from
  `https://datapub.gfz-potsdam.de/download/10.5880.GFZ.1.4.2016.001/World_Atlas_2015.zip`
  — artificial zenith brightness in mcd/m² (natural sky NOT included).
  Not committed to the repo (too big); download it yourself to regenerate.

## Method

1. Downsample by **mean in linear brightness** (mcd/m²) to a 0.25° grid
   (1440×580). Averaging in magnitudes would be wrong; magnitudes are
   logarithmic.
2. Add the natural zenith 0.174 mcd/m² and convert to SQM:
   `SQM = 22.0 − 2.5·log10(1 + artificial/0.174)`, clamped to [16, 22] —
   so truly dark cells read exactly 22.0.
3. Quantize SQM to 0.05-mag steps in one byte (`255` = unknown). The app maps
   SQM → Bortle with the conventional breakpoints (`sqmToBortle` in
   `src/lib/astro.js`); the grid stays in SQM so breakpoints can change
   without regenerating.

## Why 0.25°

Validated 2026-09-23 against 62 anchors (59 dark-sky sites with published or
map-estimated Bortle, plus Medford 8, NYC 9, San Jose 8):

| grid | within ±1 class | NYC | San Jose | Medford |
|---|---|---|---|---|
| 0.5° mean | 52/62 | 6 | 5 | 5 |
| 0.5° p75/p90 | 53/62 / 52/62 | 7 / 8 | 5 / 6 | 6 / 6 |
| **0.25° mean** | **54/62** | **8** | **6** | **6** |

0.5° cells wash cities out with their dark surroundings; percentile variants
didn't beat the finer mean grid. Costs ~1.1 MB raw (~0.4 MB gzipped) —
accepted for the accuracy. `check_percentile.py` holds the experiment.

Known caveats: data vintage is VIIRS 2015 (lights have mostly increased
since, so estimates skew slightly optimistic); a 0.25° cell still blurs sharp
city edges. Estimates are labeled "Est." in the UI with this source.

## Regenerating

```bash
python3 -m venv venv && ./venv/bin/pip install rasterio
./venv/bin/python make_grid.py /path/to/World_Atlas_2015.tif
# writes ../../src/data/bortleGrid.js
```
